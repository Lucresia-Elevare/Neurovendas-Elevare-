## Formato do Changelog

### Tipos de Mudanças

- **Added** para novas funcionalidades
- **Changed** para mudanças em funcionalidades existentes
- **Deprecated** para funcionalidades que serão removidas em breve
- **Removed** para funcionalidades removidas
- **Fixed** para correções de bugs
- **Security** para correções de vulnerabilidades de segurança

### Exemplo de Entrada

```markdown
## [1.0.0] - 2026-01-15

### Added
- Nova funcionalidade X que permite Y
- Novo prompt de vendas B2B para cold calling
- Documentação de API v2

### Changed
- Melhoria na performance do endpoint /users
- Atualização do framework de Neurovendas para v2

### Fixed
- Correção de bug em autenticação OAuth
- Correção de typo na documentação do guia de instalação

### Security
- Correção de vulnerabilidade XSS no formulário de contato
```
